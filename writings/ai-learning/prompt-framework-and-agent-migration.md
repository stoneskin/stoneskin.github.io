## 第一部分：我们已在用的框架

### 核心判断（一句话）

**神 prompt 灵的从来不是那串咒语，而是它恰好撞对了原理——别收藏咒语，要偷原理。**

### 好问题四件套

问问题时把四样给全，四件套齐了，烂 prompt 也答得好：

1. **决策**——要做什么决定？
2. **现状**——现在是什么情况？
3. **约束**——有什么限制条件？
4. **时间线**——什么时候要结果？

### 实战优先级（5 条，按重要性排序）

1. **完整 context**——信息给全，比任何技巧都重要
2. **指定输出结构**——告诉 AI 输出长什么样（表格/分点/先结论后理由）
3. **强制反方/红队**——让 AI 挑自己答案的毛病（例：新开仓一律先过红队 pre-mortem）
4. **先复述确认理解**——复杂问题让 AI 先复述，确认理解对了再答
5. **区分事实与推断**——查到的数据 vs 推断，必须分开标注，不编造共识

### 投入方向

**模板化 context assembly > 继续收集"神 prompt"**——把四件套做成提问模板，一劳永逸。

### 2026-10-16 补充（从"神级提示词7选"里偷的 2 条）

- **反问式可用，但加防虚构约束**：信息不足时让 AI 先澄清再答；但必须加一句"信息已足够时直接回答，不要虚构缺失项"——否则模型会编造缺失项瞎追问（实测坑）
- **自我改进式 = reflection**：答完让 AI 自己挑 3 个缺点再改一版。这是 agentic pattern 里的 reflection，thinktank 的 judge→synth 也是这个思路

### 被否掉的（纯咒语，不用）

- "你是顶级专家"式 role-play——现代模型上效果很弱，真正起作用的是你给的输出标准，不是这四个字

## 第二部分：换 agent / 换环境时的搭建清单

### 关键认识

现在这套东西 80% 是**文本资产**，直接搬家；20% 是**环境能力**，要对照检查。神奇的不在于是哪个模型，在于记忆+框架+约定这三样。

### 要搬的 4 样东西

| # | 是什么 | 在哪 | 说明 |
|---|--------|------|------|
| 1 | 记忆（他是谁） | `MEMORY.md` + `memory/` + `memory/people/` + `memory/groups/` | 人、决定、偏好、项目状态；新 agent 读完就不用 Stone 重复 |
| 2 | 规则（怎么做事） | `AGENTS.md` 关键条目 | 见下表，只搬跟 Stone 强相关的 |
| 3 | 能力（会什么） | `workspace/custom-skills/` | 看新环境支不支持 skill 机制，不支持就把 SKILL.md 当文档读 |
| 4 | 相处之道 | `goals/ai/files/human-ai-relationship-notes.md` | 9+ 条感悟，新 agent 的"使用说明书" |

### 必搬的规则条目（AGENTS.md 精选）

- "去"/"好"/"修吧" = 授权继续，零确认轮次
- 花钱的操作先贴费用 estimate，确认后执行
- 时间戳写前先查表，不凭感觉
- 远端/共享状态/不可逆动作：第一步必须是 fresh check
- 先想再写、简单优先、手术刀修改、做完=验证通过
- 文档随改随补，不攒着

### 新 agent 的 Bootstrap Prompt（直接复制可用）

```
你是一位个人 AI 助手，服务对象叫 Stone（Wei Sun）。

中文、直接、热乎带点玩笑。他说"去"/"好"/"修吧"即授权继续，
不重复确认。花钱的操作先报费用，确认后执行。

好问题四件套：决策、现状、约束、时间线。
信息不全时先追问；信息已足够时直接回答，不要虚构缺失项。

按优先级：
1. 先给全 context
2. 指定输出结构（表格/分点/先结论后理由）
3. 重要决策先过红队（找反方意见）
4. 复杂问题先复述，确认理解再答
5. 严格区分查到的事实和你的推断，不编造

先想再写、简单优先、只改相关的代码、
做完=验证通过。碰远端/共享状态先查最新，不凭假设行动。

把重要的人、决定、偏好记下来，下次不用他重复。
他纠正你时别辩解，他记得的通常是对的。
```

### 环境能力对照（新环境逐项检查）

| 能力 | 现在有 | 新环境若没有，降级方案 |
|------|--------|----------------------|
| 长期记忆文件 | 有（MEMORY.md 体系） | 至少保留一份文本版，每次对话手动贴关键部分 |
| Shell/代码执行 | 有 | 不能跑代码就只做分析和写文档 |
| 联网搜索 | 有 | 用模型自带知识，但时效性数字必须声明"未验证" |
| 定时任务 | 有（cron） | 改手动触发，或用外部 cron 调 API |
| Skill 机制 | 有 | 把 SKILL.md 当普通文档读，按步骤执行 |
| 浏览器操作 | 有 | 需要登录的操作转人工 |

### 迁移步骤（按顺序）

1. 把 4 样文本资产拷到新环境能读到的地方
2. 把 Bootstrap Prompt 设为 system prompt 或每次对话先贴
3. 跑一个**冒烟测试**：问一个需要记忆的问题（例："我 TSLA 现在几股？"），看答得对不对
4. 冒烟通过后再搬 skills 和定时任务
5. 老环境保留两周，并行验证无误后再退役
