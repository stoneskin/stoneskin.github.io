# 《I Deleted My Second Brain》总结

> 原文：https://westenberg.beehiiv.com/p/i-deleted-my-second-brain
> 作者：Westenberg（beehiiv 博主）
> 发表：2025-06-17
> 一句话：删光 10,000 条笔记、7 年的第二大脑，如释重负——"我不想管理知识，我想活在知识里。"

## 故事

两年前的一个晚上，作者删掉了一切：Obsidian 里所有笔记、2015 年以来同步的 Apple Notes、所有高亮、所有待办系统。删完的感觉：**Relief**（如释重负），以及"噪音消失后的舒适寂静"。

导火索：戒酒六周年让他回看旧笔记——一层层系统套系统、给未来自己许的诺。"让我熬过最艰难头三年的一切，都不在那些笔记里。"

## 核心论点

### 1. 第二大脑变成了陵墓

一层层旧的自己、旧的兴趣、旧的执念像地质层一样堆着。它没有加速思考，而是**替代了思考**；没有辅助记忆，而是把好奇心冻成了静态分类。

### 2. "我停止了好奇，开始了处理"

系统反过来塑造了注意力：读书为了摘录、听话为了总结、用能归档的格式思考。**一切体验都变成了饲料。**

### 3. 人类记忆是故意要忘的

"They forget on purpose." 人不是按文件夹思考的，大脑是即兴的、联想的、具身的。想记住一切，等于把反思这个动作外包给了结构——但**结构不是思考，标签不是洞见**。

### 4. Deferral 是 PKM 的真正产物

系统越大，越把思考的工作推给"未来的自己去整理、打标签、提炼"。**那个自己永远没来。**

### 5. 删除即设计

尼采烧草稿、米开朗基罗毁素描、达芬奇留下几千页未完成。"如果删除才是更真的纪律呢？"

### 6. 新系统：没有系统

只留一个叫 WHAT 的笔记，写几件必须记住的事。"重要的东西会自己找回来。"（The important bits will find their way back.）

## 金句

- "I don't want to manage knowledge. I want to live it."（我不想管理知识，我想活在知识里。）
- 博尔赫斯《巴别图书馆》的警告：地图吞掉了疆域（The map swallows the territory）
- 希伯来词 "zakhor"：记忆与行动同义——记住就是通过专注让过去在场

## 与 open-memex 的咬合（红队视角）

这篇是对"全量捕获"本能的红队——open-memex 正在给 agent 建记忆系统，三个可采用：

1. **"forget on purpose" 是一等公民**：忘什么跟记什么同等重要，不该只是清理脚本
2. **curation > capture**：默认不记，值得才记（D81 别名词表已是这个方向，可更激进）
3. **WHAT 笔记**：一小撮高权重记忆，而不是向量库里的几万条——对应 agent 的 working memory 设计

## 方法论互文

- 与 pstack 对冲：pstack 教"怎么建系统"，这篇问"该不该建"
- 与 Harness² 对冲：Harness² 说"harness 是变量要优化"，这篇说"有时候删掉才是优化"
- 与 incident-to-eval 呼应：沉淀的是"教训"不是"一切"——考题是 curated 的，不是全量 log
- 与 Lauren Tan 呼应：她说"你的代码库就是记忆"，这篇说"记忆会变成陵墓"——两边都是"结构会反噬"的警告
