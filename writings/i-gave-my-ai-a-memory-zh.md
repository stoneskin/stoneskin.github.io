# 我给 AI 配了个记忆

*2026-10-04 · [English Version](./i-gave-my-ai-a-memory-en.md)*

最烦人的不是 AI 写错代码，是它记性差。

上周在 VS Code 里跟 Copilot 定好的部署流程，这周换到 opencode，它问我"咱们项目是怎么部署的"。像我这样的老员工脑中的很多细碎的知识，虽然在工作时常常会输入给AI了，但它窗口一关转头就忘了。

open-memex 就是我给这个毛病开的药：一个本地记忆层。今天在一个编辑器里说的话，明天换个编辑器还记得。记忆存成 Markdown 放你自己机器上，SQLite FTS5 在上面做全文索引。想看就打开看，想改就打开改，不经过任何云。

做到 v0.8.1 了，顺手说两个我自己最爱用的功能：

**别名**：教它"烧饼计划"就是"支付系统重构项目"——对，烧饼，画大饼那个饼。人类起代号从来不讲道理，这个功能就是用来接这种梗的。设一次，以后搜代号直接命中，不用重建索引。

**同义词扩展**：中英文同义词在建索引的时候自动展开。你写中文"部署"，搜英文"ship"也能找到。一个是建索引时展开（同义词表稳定），一个是查询时展开（别名随时会加）——两套机制，分开是有原因的。

检索效果：在我们自建的小规模测试集（54 条记忆 / 44 个查询）上，召回率 recall@5 97.7%——样本量不大，仅供参考。纯本地，不调任何外部 API。

这个项目主要是我跟 Muse 结对写出来的，MiniMax 在免费测试期帮忙做了代码评审和修 Bug。

开源 Apache-2.0，`npm install -g open-memex` 一行装，已上架官方 MCP Registry。
